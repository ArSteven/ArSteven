### Featured project

**[DevConnect](https://devconnect-web-mauve.vercel.app)** — a social network where programming students learn by improving each other's code, and companies hire based on evidence they can verify.

- Students propose improvements to others' code; anyone can **run both versions side by side** (JS, TS, Python, SQL, Go) and the platform records that the improvement works.
- Companies post challenges and invite candidates to a **15-minute live defense** to check they understand their solution, not just pasted it from an AI.
- User code never runs on my servers: a sandboxed iframe with a strict CSP in the browser, Go via the official Playground.
- JWT + rotating refresh tokens, bcrypt with timing-safe login, rate limiting, 11 versioned SQL migrations.

[Live demo](https://devconnect-web-mauve.vercel.app) · [API (Go)](https://github.com/ArSteven/devconnect) · [Web (Angular 21)](https://github.com/ArSteven/devconnect-web)
